## 项目内容

本作品集展示了 4 个 AI 应用项目：

1. AI 校规问答助手  
   基于 Python + RAG + Ollama + Streamlit 搭建的校规问答系统。

2. NovaTech 企业知识库客服智能体  
   基于 Coze 搭建的企业知识库客服 Agent，支持 FAQ 问答、售后规则约束和工单摘要。

3. AI 求职岗位匹配助手  
   基于 Coze 搭建的求职辅助 Agent，支持岗位 JD 分析、人岗匹配、简历优化和面试题生成。

4. 门店评论分析与自动回复 Agent  
   基于 Python + Pandas + Coze 搭建的评论分析项目，支持评论统计、差评分类、经营周报和商家回复建议。
